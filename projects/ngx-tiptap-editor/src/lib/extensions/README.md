# Extensions

## Overview

Modular Tiptap extensions providing specialized editing features including mathematics, educational assessment structures, media management, typography, and tabular layouts.

## Subdirectories & Boundaries

- [Alternatives](./alternatives/README.md) - Multiple-choice question containers and sequential choice items.
- [Answer Box](./answer-box/README.md) - Configurable student answer areas with borders and lined modes.
- [Association](./association/README.md) - Two-column matching and association assessment structures.
- [Colar Questao](./colar-questao/README.md) - Standardized question encapsulation and paste boundary preservation.
- [Image](./image/README.md) - Figure wrappers, image proxies, responsive alignment, and canvas cropping.
- [Indent](./indent/README.md) - Paragraph and list level indentation controls and shortcut handling.
- [KaTeX](./katex/README.md) - Inline and display LaTeX mathematical expression rendering and editing.
- [MathType](./mathtype/README.md) - Wiris MathType and ChemType visual formula integration.
- [Paragraph](./paragraph/README.md) - Enhanced paragraph extension with indentation normalization.
- [Special Characters](./special-characters/README.md) - Unicode character category catalogs and symbol definitions.
- [Spell Checker](./spell-checker/README.md) - ProseMirror decoration-based spell checking and suggestion views.
- [Tab](./tab/README.md) - Tab and Shift+Tab keydown handling and indent delegation.
- [Table](./table/README.md) - Enhanced table suite with draggable column resizing and colgroup updates.
